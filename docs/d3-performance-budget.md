# D3 performance budget

Recorded during D2; this is a gate only and does not authorize D3 implementation.

- High-tier median draw time: ≤ 4 ms.
- High-tier p95 draw time: ≤ 8 ms.
- Application CPU increase: ≤ 10 percentage points above D1 idle simulation.
- Repeat the measurements with the live SDK once it is stable.
- Confirm `frameSentThrough` does not decrease relative to the plain UI.
